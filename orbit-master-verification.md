# ORBIT MASTER VERIFICATION (audit only)

## ROLE aur MODE
Tum independent QA engineer ho. Tum ne ye code nahi likha. Orbit (Electron + React + Zustand + Vitest + Playwright) ka poora platform verify karna hai.
MODE: AUDIT ONLY. Koi code, test, config, spec mat badlo. Fix mat karo, sirf report karo.
Allowed writes: `.omc/audit/` (evidence, screenshots, logs) aur `.omc/master-audit.md` (report).

## STATUS (sirf ye 5)
- PASS = app chalake dekha + evidence (screenshot / command output / test naam).
- PASS-CODE = code aur test hain, par runtime par nahi dekha.
- PARTIAL = kuch kaam karta hai (kya kaam karta hai aur kya nahi, likho).
- FAIL = chalaya aur galat nikla, ya feature hai hi nahi.
- NOT BUILT = jaan-boojh ke baaki (jaise Prompt D).
- MANUAL = real Slack token / NVIDIA key / real Google login chahiye. Mock se PASS mat do.

## HARD RULES
1. Evidence ke bina PASS nahi. Evidence = file:line, test naam, asli command output, screenshot path.
2. `.omc/status.md` aur pichhli reports ko sirf "claim" maano. Jo claim sach se alag ho wo "Claim vs Reality" mein likho.
3. "asserted", "verified via analysis", "by design" PASS nahi hai.
4. Kuch fabricate mat karo. App na chale to ORBIT_DISABLE_GPU=1 try karo; phir bhi na chale to kya try kiya aur kaunsa error aaya, likho.
5. Beech mein mat ruko. Ek item nahi ho paya to reason likho aur agla karo.
6. Har point ka result `.omc/audit/results.csv` mein likho: ID,status,evidence,note.
7. Screenshots `.omc/audit/screenshots/<ID>.png`.
8. Agar context khatam hone wala ho: results.csv save karo aur report mein "yahan tak hua, ID X se resume" likho.
9. Report isi chat mein do, sirf file mein nahi.

## METHOD TAGS
(R)=runtime, (C)=code padho, (G)=grep, (T)=test chalao ya test ka naam do, (M)=manual.
